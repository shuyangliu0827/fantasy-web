**Classification: Pre-existing — not a regression.**

The `.next/dev/` directory contains auto-generated route type stubs that reference `app/test-db/` and `app/waiver-wire/`. ### Most significant non-trivial issues

**`react-hooks/exhaustive-deps` (17 warnings)** — Missing dependencies in `useEffect` arrays can cause stale closures. These exist across many pages. Not currently causing visible bugs but represent a latent risk in data-refresh paths.

**Function-before-declaration (8 errors)** — Async `loadData` / `loadInsight` functions called inside `useEffect` before they're declared. JavaScript hoisting makes this work at runtime, but the linter flags it as a mutation-tracking issue. Affected pages: `discover/[id]`, `discover/new`, `discover`, `members`, `settings`, and others.

**Blocks product? No. All are pre-existing and unchanged since before the recent fixes.**
